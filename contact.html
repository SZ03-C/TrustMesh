Common questions

FAQ

What is a Cyber Trust Passport? A scored security assessment (0-100) evaluating domain security, email auth, exposure, and developer hygiene. It includes security badges, ID numbers, and a collaboration decision.
Is TrustMesh a vulnerability scanner? No. TrustMesh performs only safe, passive checks: HTTPS verification, security header inspection, DNS lookups, and GitHub public metadata analysis.
How do I interpret the trust score? 82+ = Safe to collaborate. 68-81 = Restricted (limited sharing). Below 68 = High Risk (fix issues before sharing sensitive data).
